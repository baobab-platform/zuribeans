# Capability demand and authority census — initial v2.0

This is a business demand census, not a declaration of new Shared keys. C
(canonical registration), P (proposal), I (source implementation), Q (protected
provider qualification) and A (per-context production activation) are independent
facts. Every state below has its own evidence cell; no state inherits another.

The pinned catalogue establishes C only. `UNVERIFIED`/`UNPROVEN` and `—` mean no
sufficient evidence is recorded in this baseline, not that source cannot exist,
that a condition is inapplicable, or that a gate passed. `BUSINESS_CANDIDATE` is
local demand, not an accepted or formally submitted Shared registry proposal.
Existing source and owner proposals must be audited before updating I or P.
Composite rows must be split into exact capability/version/context records before
claiming Q or A. No row currently establishes protected qualification or activation.
